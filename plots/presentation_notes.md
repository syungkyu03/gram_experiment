# DINOv3 Gram 실험 발표 노트

`gram_224`와 `gram_512`의 비교 결과를 정리했다. **같은 두 번의 forward에서 최종 CLS, 공간 패치 간 관계, 블록 간 CLS 관계를 각각 점수화**했다. 512에서 최종 CLS의 macro AUROC는 **0.8393**, 11번 블록 CLS는 **0.8458**, 저장된 Gram으로 추가 계산한 층간 유사도 크기 감소율은 **0.8461**이었다. 생성기별 성능과 낮은 오탐률에서의 순위는 서로 달랐다.

## 1. 실험 파이프라인

1. GenImage의 **동일한 100,000장**을 사용한다. Real 50,000장과 Fake 50,000장이고, 생성기 8개가 포함된다. 두 실행의 manifest가 일치했고 점수 행의 누락·중복·비정상 값은 0개였다. [224 실행 검증](../gram_results/gram_224/audit.json) · [512 실행 검증](../gram_results/gram_512/audit.json)
2. 입력을 **224×224 또는 512×512로 Bilinear 리사이즈**하고 ImageNet 정규화를 적용한다. 해당 입력의 복사본에 **정규화 공간에서 전역 Gaussian 노이즈**를 더한다. 표준편차는 0.05로 맞추고 클리핑을 적용하지 않는다. [224 설정](../gram_results/gram_224/config.json) · [512 설정](../gram_results/gram_512/config.json)
3. 원본과 변형본을 각각 DINOv3 ViT-B/16에 넣는다. **최종 LayerNorm 이후의 CLS와 패치 토큰**, 그리고 **각 Transformer 블록 직후의 CLS 12개**를 얻는다. 층간 비교에서는 12개 CLS 모두를 최종 LayerNorm 적용 전에 읽는다. [토큰 추출 코드](../backbone.py#L38)
4. 토큰에서 이미지당 스칼라 점수를 만들고 **점수가 높을수록 Fake**인 방향으로 AUROC를 계산한다. 두 해상도의 Gram 크기 감소율은 실행 때 저장한 상삼각 배열을 이용해 추가로 계산했다. [실험 코드](../experiment_gram.py) · [분석 코드](../analysis_gram.py)

## 2. 각 점수가 비교하는 것

코사인 유사도는 벡터의 길이를 각각 1로 맞춘 뒤 내적한 값이다. 예를 들어 원본 CLS와 변형본 CLS의 코사인 유사도가 0.98이면, 그 이미지의 CLS 코사인 거리는 **1 − 0.98 = 0.02**다.

| 방법 | 원본과 변형본으로 점수를 만드는 순서 |
|---|---|
| **최종 CLS 코사인** | 각 이미지에서 최종 CLS 벡터 하나를 뽑아 두 벡터의 `1 − 코사인 유사도`를 계산한다. 이 실험의 RIGID-style 기준이다. |
| **개별 블록 CLS 코사인** | 같은 블록에서 얻은 원본·변형본 CLS의 코사인 거리를 구한다. 예를 들어 11번 점수는 그 블록의 CLS 두 개만 쓴다. |
| **Patch Gram 코사인** | 이미지마다 최종 패치 토큰을 단위 벡터로 만든 뒤 위치가 다른 패치 쌍의 코사인 유사도를 구한다. 224는 196개 패치로 19,110쌍, 512는 1,024개 패치로 523,776쌍을 만든다. 원본과 변형본에서 쌍별 값을 같은 순서로 펼쳐 두 배열의 코사인 거리를 구한다. |
| **Block CLS Gram 코사인** | 이미지마다 12개 블록의 CLS를 각각 단위 벡터로 만들고, 서로 다른 블록 쌍의 코사인 유사도 **66개**를 구한다. 원본과 변형본에서 얻은 이 66개짜리 배열 두 개의 코사인 거리를 계산한다. |
| **Gram L1** | 패치 쌍 또는 블록 쌍마다 원본·변형본의 코사인 유사도 차이에 절댓값을 취하고, 모든 쌍에 대해 평균낸다. 예를 들어 0.60에서 0.45로 바뀐 쌍의 변화량은 0.15다. |
| **Block CLS Gram 크기 감소율** | 원본과 변형본 각각에서 **66개 층간 코사인 값**을 제곱해 더하고 제곱근을 취한다. 점수는 `1 − 변형본 크기 ÷ 원본 크기`다. 5.00에서 4.95로 줄면 +1%, 5.05로 늘면 −1%다. |

Gram은 모든 서로 다른 쌍을 한 번씩 사용한다. 두 Gram의 66개 값이 모두 같은 비율로 1% 줄어드는 단순 예시에서는 **Gram 코사인 거리 0**, **Gram 크기 감소율 1%**가 나온다. 코사인은 두 배열의 방향을, 감소율은 배열의 상대적인 길이 변화를 읽는다. [Gram 계산 코드](../metrics.py#L6)

## 3. AUROC와 해상도 비교

AUROC는 **무작위로 뽑은 Fake 한 장이 Real 한 장보다 높은 점수를 받을 확률**로 해석할 수 있다. 동점은 절반으로 센다. 0.5는 무작위 순위에 해당하고 1.0은 완전 분리다. 여기서 macro AUROC는 **생성기별 AUROC 8개의 단순 평균**이다. 특정 임계값에서의 탐지율과 오탐률은 ROC의 해당 지점에서 따로 읽는다.

| 점수 | 224 macro AUROC | 512 macro AUROC |
|---|---:|---:|
| 최종 CLS 코사인 | 0.7913 | 0.8393 |
| Patch Gram 코사인 | 0.6004 | 0.7230 |
| Block CLS Gram 코사인 | 0.7858 | 0.8017 |
| Patch Gram L1 | 0.6455 | 0.7613 |
| Block CLS Gram L1 | 0.7721 | 0.8288 |
| **11번 블록 CLS 코사인** | **0.8119** | **0.8458** |
| **Block CLS Gram 크기 감소율** | **0.6939** | **0.8461** |

## 4. 그림과 발표 요점

1. [방법별 AUROC](01_macro_auroc.png) — 동일한 GenImage 이미지에서 각 점수의 224와 512 성능을 비교한다. 512에서 CLS Gram 크기 감소율 **0.8461**, 11번 블록 CLS **0.8458**, 최종 CLS **0.8393**이었다.
2. [생성기별 AUROC](02_generator_auroc.png) — 세 대표 점수의 생성기별 결과를 두 해상도에서 비교한다. 512의 Gram 크기 감소율은 SD 1.4, SD 1.5, Wukong에서 각각 최종 CLS보다 **0.189, 0.189, 0.189** 높았다.
3. [전체 ROC 곡선](03_macro_roc.png) — 생성기 8개의 ROC를 동일하게 가중 평균했다. 곡선의 면적은 위 표의 macro AUROC다. 512의 곡선 왼쪽에서는 최종 CLS의 탐지율이 높고, FPR 범위 전체의 면적은 Gram 크기 감소율과 11번 블록 CLS가 더 크다.

11번 블록은 이 실험에서 가장 높은 단일 블록이다. Gram 크기 감소율은 저장된 층간 행렬을 보고 추가로 계산했다. 두 점수의 수치는 같은 GenImage 실험에서의 탐색 결과다. [224 AUROC 원표](../gram_results/gram_224/auroc_gram.csv) · [512 AUROC 원표](../gram_results/gram_512/auroc_gram.csv)

## 구두 발표용 요약

> 같은 GenImage 이미지의 원본과 노이즈본을 DINOv3에 각각 통과시켰습니다. 최종 CLS는 이미지 전체를 대표하는 벡터의 변화를 읽고, Gram은 패치 사이 또는 블록 CLS 사이의 관계가 얼마나 달라졌는지 읽습니다. 512에서 블록 간 유사도의 전체 크기 감소율은 AUROC 0.8461, 최종 CLS는 0.8393이었습니다. 특히 Stable Diffusion 1.4·1.5와 Wukong에서 약 0.19씩 차이가 났습니다.
